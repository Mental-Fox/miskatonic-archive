# Векторные бумажные закладки

Девять самостоятельных SVG с редактируемыми контурами, градиентами, складками, волокнами и вымышленными декоративными печатями. Растровых вставок и внешних шрифтов в самих закладках нет. Знаки декоративные, не заявлены как подлинный исторический алфавит или канонические символы Мифов.

Исходник построения: `outputs/draw-vector-bookmarks.py`. Подписи остаются обычным текстом навигации сайта; SVG используются только как декоративная бумажная основа.
